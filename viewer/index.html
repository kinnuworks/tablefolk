Every NPC is its own Switch agent

AI NPCs that can't eavesdrop.

Switch is an open-source platform that puts people and AI agents in the same chat rooms. In Tablefolk each character is its own agent, and Switch only sends it the rooms it sits in. So when the rogue sells the duke's ring in the back alley, the duke never hears a word.

Why it works

A secret stays in the room it was told in.

Most AI game masters run every character through one model. Tablefolk gives each character its own Switch agent, so what it can know is set by the rooms it's in, not by a prompt asking it to forget.

Template

One call sets the table.

The whole table is a Switch room template. Running it creates the four rooms as one linked group, seats the existing NPC agents and adds the people you name.

greywater.template.yaml
version: 2
resources:
  alley:
    type: room
    name: "back-alley-{tag}"
    channel_type: channel_private
    agents: [table-keeper, fen-the-fence]
    users: ["{gm}", "{rogue}"]
  # table, study and whisper rooms follow

Run a table

Four steps to game night.

Start Switch Console

Pick the local server with the bundled Mattermost. It needs Docker.

Add two lines to .env

The bridge address and a registration key. Add a model key, or leave it out to use Ollama.

Set the table

One command registers the agents, runs the room template and starts every NPC.

Play

Talk to a character by name. Roll, track hit points, or step aside with an NPC.

Terminal
# set the table for a GM and two players

Questions.

Is the replay a real game?

Yes, with one caveat. It was recorded on a Switch server with the real NPC agents. The player and GM lines were scripted so the scene could be re-recorded, and every NPC line was written by that NPC's agent during the run.

Couldn't a prompt keep the secret just as well?

A prompt asks a model that has read the secret not to use it. Here the duke's agent was never sent the alley, so there's nothing for it to slip. When it asks Switch for the alley anyway, it gets a 403.

Where do players type?

In Mattermost, through Switch's bridge. Each room is a channel, and the private rooms are private channels only the right people can see.

Which model writes the NPC lines?

Any of three: a hosted model if you add an API key, a local Ollama model for free, or a command-line model tool. The recorded replay used a hosted model.

What does it need to run?

Switch Console with its local server and Mattermost (which uses Docker), Node 20 or newer, and a model. Without players you can still run the scripted scene.

What's missing?

There's one campaign so far, and NPCs answer when someone names them. They don't speak up on their own or banter with each other yet.
